# GradeFlow Next v1.0 RC1 — Sakura Edition
รุ่นตรวจรับก่อนเปิดใช้งานจริง

## เจ้าของระบบ
1. ตรวจสอบ Firebase Authentication, domain ของ Vercel และ Rules ฉบับ v0.9.7.1 หรือใหม่กว่าที่ผ่าน CI
2. เข้าสู่ระบบที่ /login ด้วยบัญชีที่มี profile active และ role super_admin
3. เพิ่มนักเรียน ห้องเรียน วิชา ภาคเรียนในข้อมูลโรงเรียน หรือ import code,name จากเมนูรายงานและป้าย
4. อนุมัติคำขอครูและจัดการสอน กำหนดรายชื่อนักเรียนให้รายวิชา
5. ตรวจข้อมูลจำลองก่อนนำเข้าข้อมูลจริง

## คุณครู
เลือกการสอนและงานในเมนูตรวจงาน สร้างงานพร้อมคะแนนเต็ม สแกนกล้องหรือ USB หรือพิมพ์รหัสแล้วกดยืนยัน ตรวจคะแนนและประวัติแก้ไข ตรวจอันดับและส่งออกรายงานตามสิทธิ์
LINE: กรอก Token และ LINE ID ที่ได้รับอนุญาต กดทดสอบส่ง หากตั้งค่า LINE_SESSION_KEY บน Vercel สามารถบันทึกชั่วคราว 8 ชั่วโมงในเบราว์เซอร์เดียวได้ ล้าง Token ก่อนใช้เครื่องร่วมกัน ไม่ส่งข้อมูลนักเรียนโดยไม่มีสิทธิ์

## การย้ายข้อมูลและสำรอง
เจ้าของระบบตรวจ JSON เดิม จับคู่รายวิชาและรายชื่อ สร้างสำเนาประวัติ ก่อนนำเข้ารายการงานจริงทีละงาน ตรวจผลก่อนใช้งาน ไม่เปลี่ยนระบบเดิม
Backup Center: ดาวน์โหลด JSON ในช่วงหยุดแก้ไขข้อมูล เก็บไฟล์ในพื้นที่จำกัดสิทธิ์และเข้ารหัส ไม่เก็บใน GitHub เปรียบเทียบไฟล์กับฐานข้อมูล และกู้คืนเฉพาะข้อมูลพื้นฐานที่ขาดหายตามคู่มือ v0.9.6
การกู้คืนคะแนนและประวัติทั้งหมดรองรับเฉพาะการซ้อมใน emulator ตาม docs/v098.md ไม่รองรับการกู้คืนจริงใน production หรือกู้รหัสผ่าน Firebase Auth

## ตรวจรับก่อนเปิดตัว
- [ ] CI ครบ 8 ชุดและ Vercel Preview
- [ ] Firebase Rules และสิทธิ์บัญชีครู/เจ้าของระบบ
- [ ] Desktop, Tablet, Mobile และการพิมพ์
- [ ] สแกนกล้องและ USB จริง
- [ ] ให้คะแนน แก้ไข และประวัติ
- [ ] ย้ายข้อมูลและสำรองข้อมูลจำลอง
- [ ] ส่ง LINE จริงไปยังผู้รับที่ได้รับอนุญาต และตรวจ session/จำกัดความถี่
- [ ] ตรวจความเป็นส่วนตัว โควตา นโยบายเก็บข้อมูล และการกู้คืนจริง
ห้ามประกาศเป็นรุ่น production ที่พร้อมเต็มรูปแบบหากยังไม่ผ่านขั้นตอนตรวจรับ กรณีใช้ Spark ให้ติดตามโควตา การสำรองไม่ใช่ snapshot ณ เวลาเดียวกัน และไม่ใช่การสำรอง Firebase Auth
