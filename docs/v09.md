# v0.9 migration preview (phase 1)
Legacy source uses a decoded JSON backup with students, assignments, records and config. The preview never sends the file to a server or writes to Firebase. It reports counts and groups, validates references and score bounds, and exports a code/name-only CSV for the existing admin import. The original backup must remain intact and private; config may contain LINE credentials. No production backup was inspected.
Before historical import: confirm explicit teacher/term/course mapping, assignment scope including all-room work, preserve original timestamps, notes, leave/absent/missing distinctions, roster history, and reconcile counts. A full backup/restore tool and historical import are not implemented. Do not use the student-only CSV as a replacement for the original JSON. Test with synthetic data first. Existing Firestore rules unchanged.
