# v0.8 pilot
- Import XLSX/CSV first sheet, exact code,name headers, text IDs, 500 rows, 2 MB file limit. Existing IDs never overwritten. Partial import is retryable. Do not open untrusted XLSX files. No automatic room mapping.
- Course report exports Excel/CSV and browser print-to-PDF. Private data; only share with authorized staff. Export is not a complete backup.
- CODE128 and QR encode only the student ID. Test physical print size and scan reliability before rollout.
- LINE Messaging API remains a plan, not a live integration. A future server-only endpoint must verify Firebase ID tokens, check active role and course authorization, use recipient consent/allowlist, rate limits and idempotency, and keep channel access tokens in server environment secrets. Do not put tokens in NEXT_PUBLIC variables or GitHub. Start with synthetic messages and avoid student personal data in notifications.
- Full backup/restore, historical migration, and production device checks are deferred. Existing v0.6 rules unchanged.
