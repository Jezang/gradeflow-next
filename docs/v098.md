# v0.9.8 — Recovery rehearsal
Run from a local checkout using Node 22 and Java 21. Install dependencies. Start a local Firestore emulator using a demo project (never production). Run npm run test:recovery with FIRESTORE_EMULATOR_HOST set to localhost:8080 (or the emulator's actual port). To rehearse a trusted backup: npm run rehearse:recovery -- /private/path/backup.json with the same emulator variable. Keep real backups out of GitHub, CI, shared logs and public machines; prefer synthetic fixtures. Script requires loopback emulator address and creates a random demo-gf-recovery project. It validates known paths/references, decodes timestamps, creates documents only, reads each back and compares exact supported values. It bypasses application rules only inside the local emulator, whose rules otherwise deny all access. No production recovery, Auth recreation, indexes, infrastructure, unknown collections, or LINE settings. No full database snapshot guarantee. Partial emulator writes may remain on error; stop emulator without exporting data. This is a rehearsal, not a production restore tool.
